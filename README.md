# Clara's Career Site

Clara's AI product career portfolio — combining 8 years of global operations, commercialization, and Fractional COO experience to build and scale AI products.

网站包含面向招聘方与 AI 产品创始人的双路径内容，并预留持续更新的 PDF 简历、证书和作品集资料库。

## 本地预览

```bash
npm install
npm run dev
```

## 验证

```bash
npm test
npm run build:pages
```

## 部署到 GitHub Pages

1. 将此目录推送到 GitHub 仓库的 `main` 分支。
2. 打开仓库的 **Settings → Pages**。
3. 将 **Source** 设为 **GitHub Actions**。
4. 推送后，仓库内置的工作流会自动构建并发布网站。

如果使用自定义域名，请在部署后把 `index.html` 中的 Open Graph 图片地址改为最终网站的绝对地址，以获得稳定的链接分享封面。
