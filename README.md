# Clara Professional Portfolio

A project-led portfolio about AI product growth, commercialization, operations and AI-assisted website building.

## Local preview

```bash
npm ci
npm run dev
```

## GitHub Pages

The existing workflow builds `pages-dist/` from React, TypeScript and Vite, then deploys that directory. The build uses relative asset paths so it works under `/clara-career-portfolio/`.

```bash
npm test
```

The privacy test fails if a PDF or known private résumé reference appears in the published output. Complete résumés must stay outside this public repository. The contact forms are frontend previews; no submission service is connected, and no information is sent or saved.

## Publishing new work

Add only projects, links and results approved for public release. Company identities and quantified impact should be reviewed before publication. A full CV is shared privately after Clara reviews each request.
